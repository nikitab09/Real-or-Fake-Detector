# Fake Image Detection System

An AI-powered web application that detects whether an image is real or fake using deep learning.

## 🚀 Features
- Upload image and get prediction
- Confidence score with progress bar
- Modern UI with mobile responsiveness
- AI-based image classification

## 🛠 Tech Stack
- Python
- Flask
- TensorFlow
- HTML, CSS, JavaScript
